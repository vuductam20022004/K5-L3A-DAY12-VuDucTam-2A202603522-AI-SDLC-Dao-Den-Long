## Chạy bản ZIP

Cài Node.js22+, giải nén dao-den-long-v1.0.0.zip rồi chạy:

```bash
node dist/server.js
```

Mở http://127.0.0.1:5173 trong Chrome/Edge hỗ trợWebGL2. Không cần npm install.
WASD/Space/Shift/E/Q/P điều khiển; có đổi phím trong Cài đặt. Điểm ghi vào
data/leaderboard.json; giữ data/ khi nâng cấp. Kiểm tra SHA256SUMS.txt trước khi dùng.

```bash
node dist/server.js --export-leaderboard out.json
node scripts/bench.mjs --seed 42 --duration 30 --out bench.json
node --jitless --expose-gc dist/soak.js --seed 7 --nights 10 --out soak.json
```

Benchmark cần Chrome/Edge; CHROME_PATH nếu không tìm thấy. peak_mem_mb=null cho
bản web nhiều tiến trình. Soak dùng interpreter và GC tại hai mốc RSS công khai.
Số đo local tham khảo; không thay kết quả máy chấm. Xem README/CHANGELOG/CREDITS/LICENSE.
